# Open Interoceptomics

The atlas viewer is a download you start on your own computer. The project page is a link, and the shortcuts below are bookmarks to it.

## The atlas viewer

You need Python 3.10 or newer and a current browser.

1. [Download the ZIP](https://github.com/eliminatenoise/Interoceptomics/raw/main/downloads/atlas-viewer/Interoceptomics-Atlas-Viewer.zip) (40.5 MB) and extract all of it.
2. Open `Windows.cmd` on Windows or `macOS.command` on macOS, or run `sh Linux.sh` in a terminal on Linux.
3. The start file runs in a terminal window and opens your browser on the viewer, at an address on your own computer. Keep the terminal open while you explore.

[More in the README](README.md#open-it-in-three-steps).

## The project page and the scripts

[The project page](https://eliminatenoise.github.io/Interoceptomics/) opens in any browser. To keep it one click away, [download a shortcut](https://eliminatenoise.github.io/Interoceptomics/START.html) for Windows, macOS or Linux. A shortcut is a bookmark: it opens the page in your browser, so it always shows the current version. It does not start the atlas viewer.

| System | File | How to use it |
| --- | --- | --- |
| Windows | `Interoceptomics-Windows.url` | Download it and double-click it. |
| macOS | `Interoceptomics-macOS.webloc` | Download it and double-click it. |
| Linux | `Interoceptomics-Linux.desktop` | Download it and open it from your file manager. |
| Linux, application menu | `Install-Interoceptomics-Linux.sh` | Extract [the ZIP of all shortcuts](docs/launchers/Interoceptomics-Launchers.zip) and run `sh Install-Interoceptomics-Linux.sh` in that folder. |

The Linux installer adds one menu entry for your user and nothing else. If a different file already has that entry's name, it leaves it alone.

The shortcuts need a browser and an internet connection. The Windows and macOS shortcuts have been checked for their file format only, and have not yet been opened on those systems. The Linux installer has been run in a test folder.
