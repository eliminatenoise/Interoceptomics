# Open Interoceptomics

[Open the current preview](https://eliminatenoise.github.io/Interoceptomics/) or [download a launcher for Windows, macOS or Linux](https://eliminatenoise.github.io/Interoceptomics/START.html). The launcher opens that same current URL, so later preview updates do not require a new shortcut.

Open the current script hub, then choose the technical or simple script as PDF or editable DOCX. Your normal document viewer opens the downloaded file.

This is a partial script preview. The newer slide deck is excluded while exact image permissions remain unresolved. Older deck and model downloads are historical and do not form a matching package with these scripts.

Windows uses `Interoceptomics-Windows.url` and macOS uses `Interoceptomics-macOS.webloc`. Download and double-click the saved bookmark; neither needs a terminal. Linux uses `Interoceptomics-Linux.desktop` with the desktop's normal launcher handling. The ZIP also contains `Install-Interoceptomics-Linux.sh` for a per-user application-menu entry. Extract it, then run `sh Install-Interoceptomics-Linux.sh` in that directory. The installer opens no browser, uses Omarchy when available or xdg-open otherwise, and preserves a different file already using its managed name.

Keep file extensions and follow normal OS opening/trust prompts. These online launchers require a browser and network connection. They install no Node/Python package, paid service, model or background task. Native Windows/macOS execution and complete cross-platform behaviour remain untested; the package's checks cover file formats and isolated Linux installation only.

The start page links the available files, source ZIP, licences and current limitations. It does not turn source-only manuscripts or an absent model payload into a runnable model.
