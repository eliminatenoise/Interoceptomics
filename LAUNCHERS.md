# Open Interoceptomics

The atlas viewer opens on the project's website, and it can also be downloaded and started on your own computer. The shortcuts below are bookmarks to the project page.

## The atlas viewer

[Open it on the website](https://eliminatenoise.github.io/Interoceptomics/viewer/), with nothing to install. To use it offline, download it. You need Python 3.10 or newer and a current browser.

1. [Download the ZIP](https://github.com/eliminatenoise/Interoceptomics/raw/main/downloads/atlas-viewer/Interoceptomics-Atlas-Viewer.zip) (64.3 MB) and extract all of it.
2. Open `Windows.cmd` on Windows or `macOS.command` on macOS, or run `sh Linux.sh` in a terminal on Linux.
3. The start file runs in a terminal window and opens your browser on the viewer, at an address on your own computer. Keep the terminal open while you explore.

[More in the README](README.md#use-it-offline-download-it).

## The project page and the scripts

[The project page](https://eliminatenoise.github.io/Interoceptomics/) opens in any browser. To keep it one click away, [download a shortcut](https://eliminatenoise.github.io/Interoceptomics/START.html) for Windows, macOS or Linux. A shortcut is a bookmark: it opens the page in your browser, so it always shows the current version. It does not open the downloaded atlas viewer.

| System | File | How to use it |
| --- | --- | --- |
| Windows | `Interoceptomics-Windows.url` | Download it and double-click it. |
| macOS | `Interoceptomics-macOS.webloc` | Download it and double-click it. |
| Linux | `Interoceptomics-Linux.desktop` | Download it and open it from your file manager. |
| Linux, application menu | `Install-Interoceptomics-Linux.sh` | Extract [the ZIP of all shortcuts](docs/launchers/Interoceptomics-Launchers.zip) and run `sh Install-Interoceptomics-Linux.sh` in that folder. |

The Linux installer adds one menu entry for your user and nothing else. If a different file already has that entry's name, it leaves it alone.

The shortcuts need a browser and an internet connection. The Windows and macOS shortcuts have been checked for their file format only, and have not yet been opened on those systems. The Linux installer has been run in a test folder.

## The recorded cortex

[Open the browser viewer](https://eliminatenoise.github.io/Interoceptomics/recorded-cortex/) or extract the [recorded cortex ZIP](downloads/recorded-cortex.zip). Open the launcher named for your computer, or open `docs/recorded-cortex/index.html` directly. The measurements work offline. The brain opens from Stanford on demand or from a verified local anatomy file.

The same ZIP includes the [five-participant coverage reader](https://eliminatenoise.github.io/Interoceptomics/cortex-coverage/). Open a launcher in `docs/cortex-coverage` to start there. Its counts work offline and its surfaces open from the matching original MATLAB files.

## The stride reader

Open the 3D stride in a browser or extract the complete standalone ZIP. Inside the extracted folder, use `Open on Windows.cmd`, `Open on macOS.command` or `Open on Linux.sh`. You can also open `docs/stride-signals/index.html` directly. The animation, 200 ms marker arrows, muscle traces and plate measurements work offline. [Open the reader](https://eliminatenoise.github.io/Interoceptomics/stride-signals/) · [Download the ZIP](downloads/stride-signals.zip)

## Scalp and arm

Extract the ZIP and open the launcher for Windows, macOS or Linux in the extracted folder. Opening `index.html` there also works offline. The standard head, all 61 sites, four windows of single-person changes and seven-person agreement counts, the early scalp–eye comparison, the illustrated arm, clocks and original references are included. [Open the companion](https://eliminatenoise.github.io/Interoceptomics/scalp-and-arm/) · [Download the ZIP](downloads/scalp-and-arm.zip)

## One wrist stimulus, five recordings

Extract [the offline reader](downloads/cervical-signals.zip) and open `Open on Windows.cmd`, `Open on macOS.command` or `Open on Linux.sh`. Opening the extracted `index.html` also works. The recorded waveforms, electrode montage and rotatable reference anatomy are bundled. [Open the browser edition](https://eliminatenoise.github.io/Interoceptomics/cervical-signals/).

## Back rotation during walking and standing

Extract [the offline reader](downloads/back-rotation.zip), then open its Windows, macOS or Linux launcher or its extracted index.html. The sensor replay, voltage traces and 3D vertebrae run directly in your browser. [Open the hosted reader](https://eliminatenoise.github.io/Interoceptomics/back-rotation/)

## Inside a lifting foot

Extract the [offline muscle reader](downloads/muscle-tracking.zip) and open the launcher for Windows, macOS or Linux, or open its index.html directly. All three-dimensional anatomy and tracking steps are bundled. [Hosted reader](https://eliminatenoise.github.io/Interoceptomics/muscle-tracking/)

## When the pedal holds still

Extract the [offline atlas](downloads/pedal-load.zip) and open the launcher for Windows, macOS or Linux. The reference leg, pedal and eight Task 1 recordings are included. Opening index.html also works. [Hosted atlas](https://eliminatenoise.github.io/Interoceptomics/pedal-load/) · [Standalone 3D scene](docs/pedal-load/neutral-pedal.glb)

## Heel and force

[Open the measured walking trial](https://eliminatenoise.github.io/Interoceptomics/heel-and-force/) or [download the complete offline atlas](downloads/heel-and-force.zip). Extract the ZIP, then open `index.html`, `Open on Windows.cmd`, `Open on macOS.command` or `Open on Linux.sh`. The 3D replay, numbers, plate diagram and three target poses work without a server.
