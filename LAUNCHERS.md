# Open Interoceptomics

There are two things to open, and they open differently.

## The brain atlas

The atlas viewer is a download with a start file for each system.

1. [Download the ZIP](downloads/brain-r8/Interoceptomics-Brain-R8-Experimental-Preview-R33.zip) (40.6 MB) and extract all of it.
2. Open `Windows.cmd` on Windows or `macOS.command` on macOS, or run `sh Linux.sh` in a terminal on Linux.
3. Your browser opens the atlas at an address on your own computer.

You need Python 3.10 or newer and a current browser. [More in the README](README.md#open-it-in-three-steps).

## The project page and the scripts

[The project page](https://eliminatenoise.github.io/Interoceptomics/) is a web page: follow the link. To keep it one click away, [download a shortcut](https://eliminatenoise.github.io/Interoceptomics/START.html) for Windows, macOS or Linux. A shortcut is a bookmark that opens the page in your browser, so it always shows the current version. It is not the atlas viewer.

| System | File | How to use it |
| --- | --- | --- |
| Windows | `Interoceptomics-Windows.url` | Download it and double-click it. |
| macOS | `Interoceptomics-macOS.webloc` | Download it and double-click it. |
| Linux | `Interoceptomics-Linux.desktop` | Download it and open it from your file manager. |
| Linux, application menu | `Install-Interoceptomics-Linux.sh` | Extract [the ZIP of all shortcuts](docs/launchers/Interoceptomics-Launchers.zip) and run `sh Install-Interoceptomics-Linux.sh` in that folder. |

The Linux installer adds one menu entry for your user only. It installs no software, opens no browser while it works, and leaves alone any different file that already has the entry's name.

The shortcuts need a browser and an internet connection. The Windows and macOS shortcuts have been checked for their file format only, and have not yet been opened on those systems. The Linux installer has been run in a test folder.
