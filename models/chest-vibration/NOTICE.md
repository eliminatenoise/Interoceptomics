# Where the measurements came from

This forecast study uses the **Combined measurement of ECG, Breathing and Seismocardiograms (CEBS) database, version 1.0.0**, contributed by Miguel Ángel García González and Ariadna Argelagós Palou of the Universitat Politècnica de Catalunya. The database is available under the **Open Data Commons Attribution License v1.0**. Please retain this attribution when using the results, fitted models or other work derived from the database. [CEBS database](https://doi.org/10.13026/C2KW23) · [Database licence](https://physionet.org/content/cebsdb/view-license/1.0.0/)

The authors recorded two electrical leads, a chest breathing band and a chest accelerometer in 20 volunteers. This study selected one post-music recording each from ten people, calibrated and filtered the sensor voltages, fitted three linear predictors on five participants and compared their forecasts on the other five. The downloadable study contains fitted coefficients, error summaries, file identifiers, code and invented input examples. Full waveforms come directly from PhysioNet when reproducing the fit. [Data and acquisition methods](https://physionet.org/content/cebsdb/1.0.0/) · [Versioned file hashes](https://physionet.org/files/cebsdb/1.0.0/SHA256SUMS.txt)
