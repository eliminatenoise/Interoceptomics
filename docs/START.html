Open Interoceptomics

A wiring diagram of the nervous system shows what is connected, not what the body feels. Interoceptomics is a proposed field of science that joins the body's sense of its own interior to the mapping of nerve connections. Two things are open today: a 3D viewer for a human brain atlas, and the two scripts of a paused talk.

Open the project page

Open the atlas viewer

Download the atlas viewer (ZIP, 40.6 MB) and extract all of it. In the extracted folder, open Windows.cmd on Windows or macOS.command on macOS, or run sh Linux.sh in a terminal on Linux. The start file runs in a terminal window and opens your browser on the viewer, at an address on your own computer. Keep the terminal open while you explore. You need Python 3.10 or newer and a current browser.

Keep a shortcut on your computer

These small files are bookmarks. Each one opens the project page in your browser, so it always shows the current version. None of them starts the atlas viewer, which has its own start files inside its download.

  • Windows shortcut
  • macOS shortcut

  • All of them in one ZIP

Download the file for your system and open it. Keep its filename extension. If your browser shows the file as text instead of saving it, download the ZIP and extract it.

For an entry in the Linux application menu, extract the ZIP and run sh Install-Interoceptomics-Linux.sh in that folder. It adds one entry for your user and nothing else. If a different file already has that entry's name, it leaves it alone. Instructions · checksums · file list

The Windows and macOS shortcuts have been checked for their file format only. They have not yet been opened on those systems.
