Open Interoceptomics

A map of the wiring is not a map of what the body senses. Interoceptomics is a proposed field of science that joins the body's sense of its own interior to the mapping of nerve connections. Two things can be opened today: a 3D atlas of the human brain, and the two scripts of a paused talk.

Open the project page

Open the brain atlas

Download the atlas viewer (ZIP, 40.6 MB) and extract all of it. In the extracted folder, open Windows.cmd on Windows or macOS.command on macOS, or run sh Linux.sh in a terminal on Linux. Your browser opens the atlas at an address on your own computer. You need Python 3.10 or newer and a current browser.

Keep a shortcut on your computer

These small files are bookmarks. Each one opens the project page in your browser, so it always shows the current version. They are not the atlas viewer, which has its own start files inside its download.

  • Windows shortcut
  • macOS shortcut
  • Linux shortcut
  • Linux menu installer
  • All of them in one ZIP

Download the file for your system and open it. Keep its filename extension. If your browser shows the file as text instead of saving it, download the ZIP and extract it.

For an entry in the Linux application menu, extract the ZIP and run sh Install-Interoceptomics-Linux.sh in that folder. It adds one entry for your user only, installs no software and opens no browser while it works. If a different file already has the entry's name, it leaves that file alone.
