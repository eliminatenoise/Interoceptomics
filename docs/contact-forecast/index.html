One push, two recording days

A robot pushed the handle in a macaque’s hand. On two days, electrodes in the sensory cortex recorded the response. Could the preceding handle motion help predict how many events a contact would register in the next 100 ms?

What carries over to the second day?

The first original shown here contributed to fitting. The second is the earliest eligible pre-target push from the following day’s test. The previously inspected first original of that day was excluded. Both examples show estimates from the full Transformer with seed 17. The study evaluates three fitted seeds separately across original trials.

A shared electrode number identifies a recording contact. Each count is the number of exported unsorted events. The recordings leave individual neuron continuity, electrode coordinates for these contacts and the cause of each event unresolved. One animal and two dates set the scope.

Across 2,436 matched push windows from 609 September 13 originals, the model using the actual handle motion had lower Poisson deviance than the same model given an earlier trial’s motion. The paired difference was −0.00318 (95% block-bootstrap interval −0.00610 to −0.00071). Against a model using only earlier counts and cues, the difference was −0.00261 (−0.00697 to +0.00132). This interval includes zero. The study required an improvement in both comparisons. The displayed test original had no eligible earlier donor and contributes only to the all-eligible results.

The experiment behind the traces

Chowdhury, Glaser and Miller recorded the arm and cortex together. These three figures from their 2020 paper locate the measurements and show how the push differed from the cued reach.
