Open the extracted index.html in a browser or use the launcher for your operating system. All recordings, models and figures work from disk. A network connection is needed only to visit external references. Drag the model to turn it or focus it and use the arrow keys. Select a window, then move the sample slider with the keyboard to read exact tenths of a millisecond. Add ?site=SC6, ?site=Biceps, ?site=CP4, ?site=Thumb or ?site=ECG to the page URL to open at that channel.

Four people, one median-nerve stimulus condition
The source is OpenNeuro ds004388 v1.0.0, versioned at ab5f0cb559249cb6d82b6f763767c6fe99292886. The four training participants are sub-001 / run 03, sub-002 / run 03, sub-003 / run 02 and sub-004 / run 02. We selected run 03 where it contained the median condition, and otherwise the lowest-numbered median run. We used the first 80 events in acquisition order marked “stimulus” and “Median - Stimulation” in each run. The source metadata and complete ordered acquisition header agreed on channel order. The BIDS sample index agreed with event time in seconds multiplied by 10,000 and with the one-based EEGLAB event latency minus one. This establishes a shared recorded clock. There was no independent test of equipment latency.

The reader shows 100 native samples per channel per event: 50 from -15 to less than -10 ms, 30 from +5 to less than +8 ms and 20 from +12 to less than +14 ms. No other time points are represented. It averages the 80 events within each person and gives the four people equal weight. Baseline subtraction removes the mean across the 50 prestimulus samples for that person and channel. Because these are complete, equally weighted events, this gives exactly the mean of the individually baseline-corrected epochs. A range across the four participant means shows their spread. It is not a confidence interval. Different channels have different references and may use different vertical scales. The three windows of each displayed channel and participant choice share one voltage scale.

What was measured
Biceps records from the left axilla with its reference about 3 cm nearer the shoulder. SC6 records neck skin over the C6 spinous process versus skin over T6. CP4 is scalp EEG versus the right mastoid. Thumb is surface EMG of abductor pollicis brevis versus a proximal electrode. ECG measures the potential difference across the torso between the lower left ribs and the area below the right collarbone. Hardware acquisition included a 0.16 Hz lower cutoff and a 2,500 Hz anti-alias filter. This reader applies no new filter, artifact subtraction, spatial fit, signed-peak alignment or normalization. The participants lay still. The recordings provide no joint angles, force, travelled distance, causal direction or subject-specific source localization. Individual pulse, muscle, heartbeat and more distant electrical contributions cannot be isolated by this display.

Reproduction
Obtain the listed median runs of OpenNeuro ds004388 v1.0.0 in their original BIDS directory structure. The builder reads *_eeg.fdt, *_events.tsv, *_channels.tsv and *_eeg.json from those four runs only. Install Python 3 and NumPy, then run:
  python build_signals.py /path/to/ds004388 --output rebuilt-waveforms.js
Compare rebuilt-waveforms.js with waveforms.js. The builder checks source sidecar digests and continuous file lengths. It checks the SHA-256 of the actual selected float32 samples before averaging, then serializes the participant means in float64. sources.json gives the publisher’s whole-file SHA-256 for cross-checking downloads. Only the selected source ranges were checked locally for this edition. No raw trial arrays or session material ship with this reader.

To regenerate the model packet, run python reference/build_anatomy.py /path/to/organs.glb. The exact existing atlas GLB is identified in NOTICE.txt. The editable scalp sources are supplied under reference/scalp/. package.py builds the standalone ZIP using an explicit product list. For license terms and reference links, open NOTICE.txt.
