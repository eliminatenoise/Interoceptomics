Human camera motion sources and results

The human motion model uses five earlier tracked frames to forecast a shoulder, elbow, wrist, hip, knee or ankle in the image 120 milliseconds later. The feedback option combines it with the earlier tracking blend after observing how recent forecasts perform. NeuroTranslate 0.0 is a separate model trained on animal movement recordings.

In a recorded two-camera test with 86 people, adding the human forecast to feedback changed average endpoint error from 10.52 to 10.45 pixels. Movement error changed from 5.08 to 5.06 pixels, with uncertainty that included no change. The game offers these methods as options. A physical home webcam requires its own evaluation. Measurements and reuse

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217. The Carnegie Mellon Graphics Lab permits copying, modification and redistribution of its motion recordings and prohibits their direct resale. This project projected marker positions into different camera views. CMU terms.

Keaton Scherpereel, Dean Molinaro, Omer Inan, Maxwell Shepherd and Aaron Young supplied the Georgia Tech biomechanics recordings. This project used skin-marker sites and derived geometrical features for camera forecasts. Georgia Tech dataset · CC BY 4.0 licence.
