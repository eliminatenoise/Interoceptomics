# Data credit and licence

This folder holds version 2 of the chest-vibration forecast. Its fitted weights, results and every value derived from recordings come from the **Combined measurement of ECG, Breathing and Seismocardiograms (CEBS) database, version 1.0.0**, contributed by Miguel Ángel García González and Ariadna Argelagós Palou of the Universitat Politècnica de Catalunya and published on PhysioNet. The database is available under the **Open Data Commons Attribution License v1.0 (ODC-By 1.0)**. Keep this attribution when you use the results, the fitted weights or other work derived from the database. [CEBS database](https://doi.org/10.13026/C2KW23) · [Database licence](https://physionet.org/content/cebsdb/view-license/1.0.0/) · [Versioned file hashes](https://physionet.org/files/cebsdb/1.0.0/SHA256SUMS.txt)

The authors recorded ECG leads I and II, a chest breathing band and one axis of a chest accelerometer in 20 volunteers, at 5,000 samples per second. This study used the five-minute after-music recordings of subjects 1-20 (p001-p020) and the basal recording of subject 1 (b001). p004-p013 were used for fitting; p014-p020, p001-p003 and b001 for testing. The p002 and p003 waveforms were read from the byte-identical files b002.dat and b003.dat with the p002 and p003 headers. After the results were sealed, the beat annotations of p014-p020 (`.atr`) were used for a descriptive check of the beat detector. Every file was checked against the release's SHA-256 list.

**Our changes.** We converted the stored values to millivolts with the header gains, filtered each channel with a causal 65 Hz low-pass filter, kept a 250-per-second grid, standardised each person's readings by their 60-80 s calibration mean and standard deviation, detected heartbeats (R waves, P waves and chest-signal beats), built per-person beat templates, chose the forecast cutoffs, fitted ridge and neural-network forecasters, computed forecasts and error summaries, computed data-integrity values (checksums, calibration statistics, runs of identical values, clipped fractions), and compared detected beats with the database's annotations.

**What this folder contains that is derived from the database.** Fitted weights (`weights/`), development tables (`development/`), error summaries and detector counts (`results.json`), data-integrity values (`qc-report.json`), the detector check (`detector-check-atr.json`) and file hashes. It contains no participant waveform, beat template or forecast array; the original files stay at PhysioNet. The version 1 weights that version 2 uses as a comparison (`../chest-vibration/weights.json`) come from the same database and carry the same attribution ([version 1 notice](https://github.com/eliminatenoise/Interoceptomics/blob/8988a900a7d7f65819ee39cf69536cb06f8e4edf/models/chest-vibration/NOTICE.md)).
