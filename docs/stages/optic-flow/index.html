The fish, the camera and the moving pattern

Ryosuke Tanaka and Ruben Portugues filmed a young zebrafish while a visual pattern moved. A program chose when its direction changed. The researchers call this open loop because the fish’s movement did not set the program’s next command. The computer recorded 1,735 changes between two directions, labelled −1 and +1. These are the times in the computer’s log. The study used here could not verify exactly when the screen changed or when the fish saw it.

What counts as a change in angle

The camera measured how far the tail bent, with opposite signs for the two directions. The angle is measured in radians. A tail that holds a deep bend can have very little variation. A tail that bends from side to side can have a large spread even if its average angle is near zero.

How the spread is measured

Each forecast concerns the next tenth of a second. That interval starts at the forecast time and ends just before the following tenth of a second. It contains 19 to 21 camera readings. Find their average angle, square each angle’s distance from that average, average the squares, then take the square root. The result is the spread, called the population standard deviation. It is measured in radians too.

What went into each guess

The first rule repeats the spread from the previous tenth of a second. The next three learn how much to add to that starting value. The camera rule uses four earlier intervals of 50 milliseconds each. In each interval it uses both the average bend and the spread. Two rules add ten of the program’s direction readings from the past five seconds. The last rule uses the same spacing but looks six seconds farther back for every direction reading. An older command can still carry information about later movement.

How the rules learned and how to read a miss

The researchers’ software logs share a timeline. Forecasts were considered 320 milliseconds apart. The fitted rules learned their adjustments from 4,440 complete examples in the first two-thirds of that timeline. Fitting put inputs on comparable scales and used a penalty of 0.1 on squared slopes to limit large weights. A fixed offset had no penalty. A guess below zero was set to zero because a spread cannot be negative.

Read all windows, then one minute

The four rules made guesses for the same 2,270 later windows. Two measured answers could not be used. For each of the remaining 2,268 windows, take the distance between a guess and the spread the camera measured. The table averages these distances. Every window counts once in the overall number, so a minute with more windows contributes more.

What the comparison showed

Repeating the recent spread produced the smallest overall miss. Adding the logged command to the fitted camera rule made its average miss larger by 0.000572 radians. It lowered the miss in six one-minute blocks and raised it in fourteen. The blocks all come from this one recording, with no direct measurement of nerve activity. Testing another fish and measuring when the screen physically changed would answer different questions.

Ryosuke Tanaka and Ruben Portugues recorded the source data for Algorithmic dissection of optic flow memory in larval zebrafish. The forecasts and error summaries here were calculated from one recording in their Figure 4 archive.
