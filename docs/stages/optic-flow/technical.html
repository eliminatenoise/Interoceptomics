Measured angle and visual command

Tanaka and Portugues filmed a larval zebrafish during open-loop visual stimulation. A program set the direction of the moving pattern independently of the fish. The archive contains a signed camera-derived tail bend in radians and two logged direction codes, −1 and +1. The command changed 1,735 times at distinct software timestamps in this recording. Neither physical display timing nor the time of the fish’s sensory exposure was verified.

Target and forecast inputs

The target is the population standard deviation of 19–21 signed angles in the 100 ms beginning at the issue time. The interval excludes its right endpoint. The first forecast repeats the standard deviation from the preceding 100 ms. The fitted rules adjust that forecast using the mean and population standard deviation in four preceding 50 ms camera bins. Two rules also use ten command values at ages from zero to five seconds. The comparison shifts all ten ages back by six more seconds. Older command history can retain predictive information.

Fitting and scoring

Forecast times lie on a 320 ms grid. Training used the first two-thirds of shared camera and command time, with 4,440 complete cases. The ridge fits use training-only centring and scaling and a slope penalty of 0.1 with an unpenalized intercept. Forecasts below zero are set to zero. All four rules issued forecasts for 2,270 later windows. Two later targets were unusable, leaving 2,268 common cases. The full-set score weights each window equally, so blocks can contribute different numbers of windows.

Scope of the comparison

Across the full set, carrying forward recent camera spread gave the lowest error. Adding the logged command to the fitted camera rule increased mean absolute error by 0.000572 radians. It reduced error in six populated blocks and increased it in the other fourteen. The 20 blocks divide one recording. They provide no independent test across animals, and no neural activity was measured in this assay.

Ryosuke Tanaka and Ruben Portugues recorded the source data for Algorithmic dissection of optic flow memory in larval zebrafish. The forecasts and error summaries here were calculated from one recording in their Figure 4 archive.
