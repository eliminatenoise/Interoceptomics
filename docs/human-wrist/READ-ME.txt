ONE WRIST REACH
Interoceptomics · Experimental atlas, edition 2

Extract the entire ZIP before opening index.html or the Windows, macOS or
Linux launcher beside it. The viewer starts with a fictional signal, contact
layout and two drawn arms. The signal comes from two sine waves. No clinical
measurements, images, individual-fit weights or participant geometry are in
this download. The reader works offline without a server or a fixed port.
Ordinary standard browser security settings suffice.

Try the controls
Choose a 3D plane or rotate the contacts by dragging. Shape marks grid, strip
or depth. Select a contact, scrub one 2 ms step at a time using the arrow keys
on the slider, or click on its voltage trace. Pin a time and move the cursor.
The comparison reports the voltage change and the displacement between the
two displayed right-wrist positions in the camera plane. A blank camera panel
means that the window has no preceding frame. The two clocks stay independent.

Make the recorded example
The recorded view opens one specific JSON file made on your machine. For a
new Python environment, open a terminal in this extracted folder and run the
appropriate commands (Python 3.11 or later).

Linux/macOS
  python3 -m venv wrist-env
  wrist-env/bin/python -m pip install -r requirements.txt
  wrist-env/bin/python prepare.py --fetch --out wrist.json

Windows
  py -3 -m venv wrist-env
  wrist-env\Scripts\python -m pip install -r requirements.txt
  wrist-env\Scripts\python prepare.py --fetch --out wrist.json

The fetch option reads bounded HTTP ranges from a single versioned DANDI
asset to temporary storage. It verifies their offsets, lengths and ETag and
checks every extracted array against its digest. The conversion needs access
to the archive. Afterward choose wrist.json under Open a recording. The
reader checks the file locally and makes no upload. Use the Close recording
button to return to the fictional example. Closing the tab clears the view.

Two offline inputs work with the same installed requirements. In the commands
above, replace --fetch with either --nwb "path/to/file.nwb" for the original
whole file or --npz "path/to/first-window.npz" for the exact ten-array derived
window. A full original file must match DANDI's SHA-256 and the NPZ must
match its own fixed SHA-256. Choose a new output filename on each invocation.
