One wrist reach

An electrode gets 500 readings in a second. A camera gets 30 frames. Turn the contacts, follow each arm and see which frame was available when the voltage changed.

Open the recording on your device

The local reader accepts one verified second from AJILE12. Download the offline edition and follow the conversion steps to make the JSON file. Once you have it, this page works offline too.

Make the JSON from DANDI
  1. Download the standalone edition and extract it. Open a terminal in the extracted human-wrist folder.
  2. Use Python 3.11 or later. In your own Python environment run python -m pip install -r requirements.txt. Windows users can substitute py -3 for python, macOS and Linux users python3.
  3. Run python prepare.py --fetch --out wrist.json. The converter retrieves selected ranges from the original DANDI archive, checks ten arrays, then writes the one-second example to a new file on your machine. Choose wrist.json above.

Already have the original NWB? Use python prepare.py --nwb PATH_TO_NWB --out wrist.json to convert offline. The original day file is 15.9 GB. The converter checks its SHA-256 first. Source identity, the ten-array alternative and installation details are in the offline guide.

What AJILE12 measured

One movement during an ordinary day

Peterson and colleagues recorded 12 people during inpatient epilepsy monitoring over 55 days. This example uses the earliest eligible right-wrist onset for the first participant on their first available day, session 3. The annotation came after the movement. The converter takes half a second before the annotation and half a second after it. Versioned release · Movement detection methods

What an electrode records

The electrode table links each electrical channel to its contact. Shapes mark grid, strip and depth contacts. The reader hides contacts flagged by the authors’ daily noise screen until you select them. The others can still carry artifacts. The authors filtered the recordings, reduced the rate to 500 Hz and referenced contacts to their group median. Stored values read in microvolts. Colour shows signed voltage; the display saturates at the chosen scale limits. The trace retains the full values.

The authors located contacts using CT and MRI and mapped them into Montreal Neurological Institute (MNI) space. The dots show those positions. The electrode table does not specify axis conventions, physical coordinate units, template version or localization error. These recordings cannot establish a specific pathway or locate the source of a deflection. Original contact maps and signal quality

What the camera sees

Each arm has three tracked points, shoulder, elbow and wrist. DeepLabCut estimated their positions in one camera image. The authors’ file writer copied image pixels into a field nominally labelled “meters,” with an undefined conversion. The axes here use pixels at equal scale, increasing rightward and downward. Tracking mistakes and occlusion affect the trace. The file supplies neither metric depth nor confidence for each frame. Original movement display · Authors’ file writer

Which frame belongs to this voltage?

The recording clock starts at zero for both streams. The reader calculates original sample and frame indices from the imported time grids. The display holds the latest included frame at or before the current electrical sample. The camera panel stays blank until the first included frame arrives. The frame age measures the gap between released sample times. The study used video timestamps for alignment; residual timing error and drift are unknown here. Study design and acquisition
