# The scripts of *I Know Kung Fu*

**The talk is paused. These are its two scripts**, as they stood on 4 November 2026.

*I Know Kung Fu* is the talk in which Interoceptomics is proposed. In the film, a skill is loaded into a brain through a cable. The talk asks what a real version would have to measure, and it begins small: can recorded signals predict a movement that was measured separately?

## What the talk covers

| Slides | Part |
| --- | --- |
| 1–6 | **The promise.** A film, a comic-book telepath, and twin sisters whose two brains are connected. What would a working link between nervous systems have to show? |
| 7–13 | **A map is not enough.** The human genome was sequenced, and most rare diseases still have no approved treatment. Form limits function; it does not test it. |
| 14–24 | **What learning machines got right.** Representation, context and grounding. |
| 25–35 | **Start with movement.** A movement can be measured from outside, so a prediction about it can fail. |
| 36–74 | **Kung fu the hard way.** Six proposed stages in a small model animal: from relating brain recordings to body movement in one task, to passing help from one nervous system to another, to help from a software agent. |
| 75–82 | **Muscle first, organs next, then humans.** Sensing tied to muscle (the talk's word is *myoception*) and sensing tied to the organs (*visceroception*). |
| 83–89 | **Two papers and a new field.** Slides 87 and 88 propose Interoceptomics: interoception plus connectomics. |
| 90–102 | **Kung fu the "easy" way.** Four proposed tasks for people, using recordings from the scalp (EEG), recordings of muscle activity (EMG) and cameras. |
| 103–111 | **Where it leads.** Slide 108 is the still picture of what the [atlas viewer](../../README.md) now lets you turn: the brain regions linked to moving the body, to running its organs, and to both. |

## What the scripts are not

Beyond the studies they cite, everything in the scripts is a proposal. None of the experiments has been run, and no skill has been transferred to anyone.

The scripts describe pictures you cannot see here. The slides are not published, because 22 of their 88 pictures have not been cleared for redistribution, among them film stills, a photograph of the twins and a broadcaster's illustration.

EMG is a recording of muscle's electrical activity. It is not a recording of nerves. Where the scripts pair it with a brain recording, they still need a separately measured movement to check any prediction against.
