Change
The JSON crop retains exact left annotation IDs 10424 (VPL) and 10425 (VPM) as
values 1 and 2. It encodes all other voxels within the crop as 0. Source indices
are zero-based and stored in R, A, S order, with S changing fastest. Crop size is
34 × 27 × 30 with first voxel centre at index [149, 212, 136]. The source qform
adds 0.5 mm per index step to a whole-volume origin at [−98, −134, −72] mm in
right–anterior–superior (RAS) coordinates. The 3D frame uses (−R, S, A)/1000 in
metres. Each slice is at an original voxel centre. Only adjacent VPL and VPM
labels in that plane produce a shared edge. There is no interpolation. The
underlying MRI, independent publication figures and the original full volume
are outside this download.
