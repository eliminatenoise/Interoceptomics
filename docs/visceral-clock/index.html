Between two pressure readings

Researchers measured pressure inside an isolated mouse colon and recorded electrical activity in the pelvic nerve attached to it. Both recordings used the same clock. Where did a marked nerve event fall between readings of the pressure gauge?

Choose a marked nerve event

What fits in a tenth of a second?

The recording clock counts in steps of 8 microseconds. The pressure gauge takes a reading every 100 milliseconds. That lets us place the nerve event within the gap. The pressure values at either end and the pressure at the event itself are unknown here.

About the recording

Brierley and Brizuela deposited this recording from mouse R481. Each example uses the first mark saved on one of two nerve-event channels. Which nerve fibre produced each event, which treatment was in effect and which part of the trial was underway remain unknown.
